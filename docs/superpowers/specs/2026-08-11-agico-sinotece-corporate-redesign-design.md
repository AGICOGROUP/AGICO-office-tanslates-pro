# AGICO CEMENT × SINOTECE 企业形象页重设计规范

## 目标

在不改变西班牙语技术内容、表格和项目图片页主体结构的前提下，将演示文稿升级为跨国工程企业的联合品牌形象。重点重设计第 1、2、3、15、21、35、38 页；其余页面仅统一双品牌抬头。

## 受众与传播任务

面向海外水泥、石灰及工程项目客户。观众应快速感知 AGICO CEMENT 与 SINOTECE 的联合品牌、国际工程能力、制造实力和项目交付经验。

## 视觉系统

- 风格：瑞士国际主义网格与高端工业纪实影像的混合体系。
- 主色：深海军蓝 `#0B1F3A`、AGICO 蓝 `#006CB7`、SINOTECE 红 `#D4142A`、暖白 `#F5F4F0`。
- 版式：严格网格、大字号对比、直角色块、细线分隔；不使用渐变、拟物效果、圆角卡片或大面积阴影。
- 字体：现代无衬线字体，标题使用 Aptos Display 或可用的等效字体，正文使用 Aptos；西班牙语重音符号必须完整显示。
- 图片：仅使用当前演示文稿和参考 PDF 中的真实工厂、项目、发货及安装图片；不生成虚构企业素材。

## 重点页面

### 第 1 页：联合品牌封面

- 左侧使用高质量工业实景图，右侧为暖白或深海军蓝信息区。
- 展示 AGICO CEMENT 与 SINOTECE 联合标识。
- 主标题保持西班牙语企业介绍含义，副标题保留 Heze Shuanglong Metallurgical Machinery 制造基地信息。
- 控制信息密度，删除原页面圆点和旧蓝色图标。

### 第 2 页：目录

- 使用 01-05 大编号网格。
- 保留五个西班牙语章节名称。
- 通过蓝色主轴和 SINOTECE 红色锚点形成节奏，不使用按钮式目录卡片。

### 第 3、15、21、35、38 页：章节幕封

- 五页使用同一版式系统，但通过左右图文互换和不同工业图片形成节奏。
- 使用大号章节编号、简短西班牙语章节标题、细红蓝基线及双品牌标识。
- 章节对应：公司介绍、制造过程、项目业绩、发货照片、公司服务。

## 其他页面

- 不改变主体文字、表格、图片、流程图、动画和版式。
- 删除现有右上角旧蓝色图标，替换为标准 SINOTECE 标识。
- 与现有 AGICO CEMENT 标识组成统一双品牌页眉，保持固定尺寸、间距和安全边距。
- 第 1、2、3、15、21、35、38 页不套用普通页眉规则，由各自重点版式处理。

## 素材与品牌真实性

- SINOTECE 标识从用户提供的 `AGICO SINOTECE Profile.pdf` 提取，不手绘或仿制。
- AGICO CEMENT 标识沿用当前 PPT 中的真实品牌资产。
- GitHub 归藏 PPT 项目仅提供网格、字号对比、克制装饰和 hero 页节奏参考，不复制其 HTML 模板或第三方品牌内容。
